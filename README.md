# Bocon — Homepage Design Options

Modern homepage concepts for **Nanjing Bocon Science & Technology Co., Ltd** (南京博热传感科技有限公司), a manufacturer of precision temperature sensors (RTDs, thermocouples, heat-meter sensors, Pt100/Pt1000 elements, transmitters, and test equipment).

Two design directions reimagine the current site for 2026 while keeping the existing **BOCON wordmark**, the steel-blue/navy brand colours, and **Helvetica Neue** as the typeface.

## What makes it "2026"

- Slim sticky glass header with a single strong call-to-action
- A confident, larger type scale and generous whitespace
- Asymmetric hero with floating spec "chips" / a ruled spec table
- Bento / indexed product layouts instead of identical boxes
- Soft depth (shadows, rounded corners) and tasteful scroll & hover motion
- A brighter accent blue alongside the established steel

## Notes

- Hero and lab visuals are **CSS-drawn placeholders** where real product / facility photography would go — adding real imagery will lift both directions significantly.
- The accent blue can be dialled back toward the existing steel if it reads as too energetic.
